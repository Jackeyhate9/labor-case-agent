Labor Case Agent · v0.2 desktop

本地服务控制台

桌面壳、案件 API 与完整 Next.js 工作台均在本机运行。服务健康后将自动进入工作台。

正在启动本地 API…

首次启动可能需要数秒解压 sidecar。

数据位置

%LOCALAPPDATA%\LaborCaseAgent\data

卸载应用不会自动删除案件数据。删除前请先导出并确认备份。

模型位置

%LOCALAPPDATA%\LaborCaseAgent\models

大型模型不随轻量安装器下载；只有校验清单后才应启用。

安全边界

API 只绑定 127.0.0.1:17831。不要通过端口转发、代理或防火墙规则将其公开。
