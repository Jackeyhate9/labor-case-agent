# 仲裁线下材料包审计

## 来源与范围

本次只读审计用户提供的 `2bb0130a4e614ecdbb06bf2b7933ab77` 目录，共 29 个文件：13 个 DOC、8 个 DOCX、5 个 JPG、3 个 PDF。材料主要来自北京市朝阳区劳动人事争议仲裁委员会，包含法律依据、申请提示、管辖通知、立案表格、证据交换与出庭材料、流程和注意事项。

发现两组完全重复文件：两份授权委托书 PDF，以及两份委托代理人告知书和材料清单 DOCX。程序不应重复内置或展示。

## 可吸收能力

优先吸收字段结构和办理关系，而不是复制旧模板：

1. 仲裁申请书：申请人、被申请人、仲裁请求、事实理由、签名日期。
2. 送达地址确认书：收件人、详细地址、手机、邮箱、送达方式。
3. 证据材料清单：编号、名称、种类、原件状态、证明目的、页数。
4. 案件审理要素表：入职、岗位、劳动合同、工资、社保、工作截止时间和解除情况。
5. 线下办理核对：身份证明、打印份数、证据原件、视听资料书面记录、举证期限和出庭材料。

## 实现边界

- 不把下载的 DOC、PDF、JPG 原件打包进 EXE 或用户导出包。
- 生成文件标记为“辅助预填版”，不冒充仲裁机构制式表格。
- 未知的身份证号、地址、电话、日期、金额和代理权限保留为待填写项，不自动推断。
- 事实与理由只使用 `user_confirmed` 事实；未确认 OCR/模型结果不得进入申请书。
- 北京市管辖通知、朝阳区窗口流程、短信送达限制和历史份数仅作为来源明确的参考，不能当作全国通用规则。
- 份数、签章、送达方式和截止日期必须提示用户以拟提交仲裁机构最新要求为准。

## 材料中的参考打印要求

- 单一被申请人的申请书通常一式四份，材料描述为提交三份、本人留存一份；共同被申请人时通常增加副本。
- 身份证原件供核验，并准备 A4 复印件。
- 证据清单及证据复印件通常一式两份；共同对方时材料提示一式三份。
- 视听资料通常准备两份拷贝及两份完整书面对话记录。
- 证据复印件分类编号，开庭携带原件。

以上均属于这批地方材料的参考内容，不是软件作出的现行法律结论。
