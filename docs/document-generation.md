# 文书生成与导出

每次生成创建不可变 DocumentDraft 版本，包含：生成时间、已确认事实 ID、引用证据 ID、排除的未确认事实数、金额版本和免责声明。

固定模板生成事实摘要、仲裁申请书草稿、请求明细、证据目录、欠薪明细、时间线、第三人说明、待补证清单、调解底稿和复核清单。导出前 Safety Review 阻断未确认事实、无来源金额、伪造引用、保证胜诉和缺失免责声明。

ZIP 保留原始证据字节，不重新编码图片/PDF；manifest 记录每个文件 SHA-256。DOCX/PDF/XLSX 需通过结构与渲染检查后才能标记成功。

## 线下立案材料包

案件“导出档案”页面可生成 `offline-filing-pack.zip`，包含申请书、送达地址确认书、证据材料清单、案件审理要素表和线下办理核对清单的 DOCX 预填版，以及来源与适用范围说明。

预填内容复用案件中的当事人、地区、请求、工资、证据和用户已确认事实；缺失字段统一显示 `[请本人填写]`。模板字段结构参考用户提供的北京市朝阳区公开下载材料，但不复制原文件、不内置地方徽标，也不宣称是仲裁机构制式表格。提交前必须由用户按照拟提交机构的最新要求复核份数、签章、送达方式、时效、管辖和金额。
