# 已知限制（v0.2）

- 应用仍是单机工作台，没有生产级账户、组织、多租户认证或每次启动的随机 API 令牌；同一 Windows 用户下的其他进程可能访问回环端口。
- Unlimited‑OCR 的已验证路径需要 NVIDIA CUDA 与约 12 GB 峰值显存；无 GPU 时路由会降级到 Paddle/Windows/RapidOCR，均不可用时明确要求人工录入。Windows OCR adapter 目前仍是可检测但未配置的后备实现。
- OCR、音频转写、候选事实、证据审查和抗辩模拟都可能出错；机器结果不会自动成为已确认事实，原件、定位框和时间戳必须人工复核。
- MOSS、BGE‑M3、Nemotron 与 Unlimited‑OCR 在源码运行模式已真实验证，但大型模型运行时不内置于 Windows 安装器。`dist/models/` 附带权重和逐文件 SHA‑256，使用者仍需按发布说明复制模型并配置兼容运行时。
- Windows 安装器的最终 provider profile 以 `dist/desktop-build-manifest.json` 和发布说明为准；未内置的 provider 会显示 unavailable，不会伪装推理结果。
- 联网 LLM 设置只管理 provider、离线阻断和密钥状态；v0.2 的证据审查/抗辩输出采用仅基于已确认事实的确定性规则，不会为了“像 AI”而调用云端生成虚假事实。
- 版本化 embedding 当前存储在 SQLite JSON 中，适合单机中小案件；它不是面向百万级向量的专用向量数据库。模型关闭或当前版本尚未重建索引时使用词法搜索。
- 上传安全包含危险扩展名、双扩展/可执行文件头检查、身份证号/手机号脱敏与日志过滤，但不包含完整杀毒引擎或沙箱；来源不明文件仍应先用组织认可的安全工具扫描。
- 安装包尚未 Authenticode 签名，没有自动更新、SBOM 或完整供应链证明，Windows SmartScreen 可能提示未知发布者。
- 法律目录只含有限元数据；仲裁时效、管辖、法律适用、电子签章和网上提交必须由专业人员另行核验。
- 经济补偿、违法解除与未签合同二倍工资仍是候选估算，不替代法律意见。
