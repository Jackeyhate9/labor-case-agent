# 隐私与安全

## 默认策略

- 数据默认写入本机 SQLite 和 `data/cases/`，不启用遥测。
- LLM、embedding 默认关闭；RapidOCR 在本地运行。
- API Key 只从环境变量读取，不写数据库、日志或导出包。
- 云 provider 启用前必须展示将发送的文本/图片，并提供仅发送脱敏文本选项。

## 数据处理

- 原文件、处理结果和导出按案件分目录；不放在 Web 静态目录。
- 日志掩码身份证、银行卡、手机号和 API Key。
- 文件名清洗、允许列表、大小上限、SHA-256 与重复检测在落盘边界执行。
- 文件读取和资源更新校验案件归属；富文本按纯文本呈现，禁止直接注入 HTML。
- 案件级删除覆盖数据库记录、原文件、处理文件和导出。

## 用户责任

用户应在上传前确认其有权处理材料，导出前复核收件人和脱敏范围。单机开发模式不等于生产级多用户隔离；对外提供服务前必须增加认证、传输加密、密钥管理、备份和审计告警。
