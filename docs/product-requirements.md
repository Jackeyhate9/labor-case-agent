# 产品需求：劳动争议案件工作台

## 产品边界

本项目帮助中国大陆劳动者整理材料、核验事实、形成时间线和金额明细，并生成可复核的劳动仲裁文书草稿。它不是 AI 律师，不承诺胜诉，不自动提交仲裁。

> 本系统仅提供材料整理、信息提取、计算辅助和文书草稿，不构成正式法律意见。重要事实、金额、法律适用、时效、管辖和最终提交内容必须由用户本人、法律援助人员或执业律师复核。

## MVP 范围

- 拖欠工资。
- 劳动关系确认或未签书面劳动合同。
- 解除劳动关系、经济补偿或违法解除争议。
- 一个案件可包含多个请求，但冲突或重复金额必须提示。

## 核心闭环

创建案件 → 上传证据 → 本地解析/OCR → 机器候选事实 → 用户确认/修改/拒绝 → 来源可追溯时间线 → 工资明细与请求 → 证据缺口和对方抗辩 → 文书快照 → DOCX/PDF/表格/ZIP 导出。

## 验收优先级

P0 是证据安全、事实状态、来源回链、Decimal 金额、确认事实过滤、案件删除和可复现导出。P1 是劳动关系要素、缺口、抗辩、provider 自检和响应式 UI。P2 才是向量检索、复杂法律检索和多人协作。

## 非目标

- 自动替用户提交仲裁。
- 生成未经核验的法律条文或确定性结论。
- 把 OCR 或 LLM 输出直接写入最终文书。
- 第一阶段完整覆盖加班、工伤、竞业、平台用工和群体争议。
