# v0.2 桌面版安全说明

## 边界与默认配置

桌面版在 Windows 本机启动两个子进程：FastAPI sidecar 监听 `127.0.0.1:17831`，Next.js 工作台监听 `127.0.0.1:3000`。二者均不监听局域网地址。Tauri WebView 的 CSP 只额外允许访问这两个回环地址。

案件数据、日志和模型目录位于 `%LOCALAPPDATA%\LaborCaseAgent\`。卸载程序不会被视为可靠的数据擦除工具；交付或转让电脑前应单独清理该目录并确认备份策略。

## 已知风险

- v0.2 没有为本机 API 生成随机会话令牌，也没有操作系统级进程鉴权。同一 Windows 用户下的其他进程可以请求回环 API。不要在不受信任的软件同时运行时处理敏感案件。
- 安装包尚未进行 Authenticode 代码签名，Windows SmartScreen 可能提示未知发布者。发布者应在分发前签名并公开 SHA-256。
- 安装包包含 PyInstaller sidecar、Next.js standalone 产物和 Node.js 运行时。Node.js 二进制来自构建机已安装版本；公开分发前仍需完成第三方许可证/NOTICE 汇总。
- v0.2 不包含自动更新、签名更新清单或供应链证明。升级前应校验发布渠道和哈希。
- NSIS 安装器不内嵌模型权重，也不会自动下载；独立的 `dist/models` 载荷附带逐文件 SHA-256。手工放入的模型代码仍可能被模型加载器执行，只使用可信来源、固定 revision 和已核对哈希的文件。

## 进程生命周期

正常关闭 Tauri 主窗口时，应用会终止其 API 和 Web 子进程。崩溃或强制结束主进程时可能留下孤儿进程；可检查端口 `17831`/`3000` 后，仅终止路径属于安装目录的进程。不要按进程名批量结束系统中其他 Node.js 服务。

## 发布前最低要求

1. 为安装包签名并记录签名主体、时间戳服务和 SHA-256。
2. 为 API 增加每次启动随机令牌，并限制 CORS/Origin。
3. 生成 SBOM 与完整第三方许可证归档。
4. 对模型固定 revision、文件清单和 SHA-256，并在独立环境验证。
5. 在干净 Windows 10/11 虚拟机验证安装、启动、退出、卸载和数据保留行为。
