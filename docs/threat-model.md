# 威胁模型

| 威胁 | 入口 | 控制 | 剩余风险 |
| --- | --- | --- | --- |
| 路径穿越 | 上传文件名、下载 ID | 随机存储名、resolve 后验证 storage root、禁止执行扩展 | 操作系统/依赖漏洞 |
| 恶意文件 | 上传、压缩包、PDF | 类型/大小允许列表，不执行上传内容，限制解压 | 解析器零日漏洞，生产需沙箱 |
| 跨案件访问 | 资源 ID 枚举 | 每次反查 case/owner scope | MVP 无强认证，不适合公网多租户 |
| XSS | OCR/证据文本 | JSON API、React 转义、禁止原始 HTML | 第三方预览器风险 |
| 模板注入 | 文书字段 | 固定模板、纯文本变量、禁止执行表达式 | 复杂自定义模板未开放 |
| Prompt Injection | 证据正文 | 不可信数据分隔、严格 schema、工具权限隔离、Safety Review | LLM 仍可能受诱导，默认关闭 |
| 敏感日志泄漏 | 异常、请求日志 | 掩码过滤、禁止记录 body/key | 第三方库日志需持续审计 |
| 云端外传 | LLM/vision provider | 默认关闭、显式告知、脱敏模式 | 用户误配置或 provider 保留策略 |
| 金额错误 | OCR、LLM、浮点 | 用户确认、来源字段、Decimal 纯函数、公式展示 | 错误输入仍需人工复核 |
| 未确认事实进文书 | workflow/draft | confirmed-only 查询、快照、安全审查测试 | 新模板需回归测试 |

## 生产前必做

接入认证授权、TLS、加密备份、密钥库、杀毒/沙箱解析、依赖扫描、速率限制、CSRF 策略、数据保留策略与事件响应演练。
